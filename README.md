# 旅平險組合方案試算報價系統（昶勝軍）

富邦人壽 高秉通訊處・昶勝軍 團隊共用。編輯器最上方「業務員資料」填寫姓名／職級／電話（只存在自己的瀏覽器，與意外險報價工具共用 localStorage `cs-agent-profile-v1`，填一次即可）；客戶頁連結、三方案總表圖、頁尾署名都會帶出填寫的業務員。未填寫或舊連結沒有業務員資料時只顯示「昶勝軍」。

改編自同仁的旅平險三方案報價工具（原版：mhchen87/nanen-travel-quote，115/10/06 12:15 版）。純靜態網頁，免伺服器、免建置。

- `editor.html`：業務用編輯器（內部使用）。填目的地／年齡／日期 → 三方案即時預覽 → 下載三方案總表圖（PNG，適合 LINE）或複製客戶頁連結。草稿自動存在瀏覽器 localStorage（`yt-tq-editor-draft-v2`）。
- `index.html`：客戶頁。報價資料全部壓縮在網址 `#q=…` 裡（不經任何伺服器）；沒有資料時顯示內建範例（紅色「範例」標記）。

## 費率來源（與原版相同，未新增任何費率）
- 人壽：`js/life-rates.js`／`data/life_rates_gpta.json`，GPTA 離線表：旅行社／快易保 × 國外亞洲14國 × OAA 投保 × AT1 100～2000萬（每100萬，OH1=MR=AT1×10%）× 1～30天；未滿15歲另有 MRC 60萬＋OH1 60／120萬表。
  其他情況（申根／國外其他、OAA 不投保、AT1 非100萬整數倍如1250萬、OH1/MR 非10%、超過30天）→ 請用 GPTA 試算後手填。
- 產險：`js/presets.js`，新快樂旅綜+（海外逍遙醫療升級版）115.04 DM，計畫一／計畫二 一般・租車・兒童，保費只到 2～10 天；其他天數請向產險試算後手填。

## 與原版的差異
1. 品牌：昶勝軍 logo、富邦人壽 高秉通訊處・昶勝軍（固定）；業務員姓名／職級／電話由使用者填寫（客戶頁可點擊撥號）。
2. 每個方案可勾「含人壽」「含產險」→ 支援 純人壽／純產險／壽＋產。預設：方案一 純人壽、方案二 純產險、方案三 人壽＋產險（推薦）。
3. AT1 可選 50 萬刻度（例如 1250 萬）；非 100 萬整數倍不會自動查表，需手填保費。
4. 方案主畫面直接有「人壽保費／產險保費」手填欄位（原版藏在進階）。
5. 天數（fr6 起）：依出發／回程「日期＋時間」計算，**每滿 24 小時算一天，未滿 24 小時以一天計**（同富邦產險 B2B／人壽系統；人壽、產險共用）。
   例：115/11/10 10:00～115/11/15 10:00＝5 天；～11/15 10:01＝6 天；～11/16 10:00＝6 天；同日來回＝1 天。
   時間未填：視為出發、回程同一時刻（只填一邊則另一邊比照）→ 天數＝日期相減（不再算頭算尾）；編輯器會提醒補填班機起飛時間與回到台灣的時間。
   「投保天數覆寫」（行程進階）仍可手動指定天數。
   舊連結／舊草稿（fr6 以前，無 `dayRule: "h24"`）：沿用原報價天數（舊版以日曆日算頭算尾），不會默默改價；編輯器提示依 24 小時制應為幾天，修改日期或時間後才改用新制。客戶頁一律顯示連結內的天數與保費。
6. 恢復「複製客戶頁連結」「開啟客戶頁」按鈕（原版最後一版拿掉了，但客戶頁仍支援）。
7. 簽名改為頁首「業務員資料」（姓名／職級／電話），兩個報價工具共用。
8. 依富邦人壽 Go安行 DM（1150731）與條款補齊人壽保障顯示（見 `../reference_docs/`）：
   - 人壽組合：國外旅遊適用（OH1／MR＝AT1×10%）或 國外旅遊醫療加值（AT1×20%，上限250萬；91～100歲10%）。
   - 海外特定地區限額（DM 第2頁 註3、OH1 條款第十一條）：美國、加拿大 350%；日本、歐洲、紐澳、南韓 200%；其他 100%；只調整住院・門診・急診。客戶頁、總表圖顯示所套用的地區與係數。關島／塞班／俄羅斯／土耳其等 DM 未明列的地點不自動加倍，編輯器會提醒確認。
   - 交通意外加倍（AT1 條款第六、七條）：搭乘大眾運輸工具・騎乘自行車・駕駛或乘坐汽車意外身故／失能，除一般意外外另按保額加給一倍 → 顯示「交通意外身故 2×AT1（＋產險）」。
   - 人壽其他保障：重大燒燙傷（AT1 20%＋海外 OH1 100%）、返國住院（OH1 30%）、住院補償（實支住院 10／15／20%）。
   - 目的地英文關鍵字改用單字邊界（避免 Phuket 被當成 UK、South America 被當成美國），「突尼斯」不再被當成法國尼斯。

## 發佈到 GitHub Pages
1. 建立 GitHub 帳號與一個 repo（例如 `yt-travel-quote`）。
2. 把本資料夾全部檔案（含 `.nojekyll`）上傳到 repo 根目錄。
3. Settings → Pages → Source 選 `Deploy from a branch`，branch `main`、資料夾 `/ (root)`。
4. 網址會是 `https://<帳號>.github.io/<repo>/editor.html`（客戶頁為 `.../index.html#q=…`）。
注意：GitHub Pages 免費版的 repo 必須是 public（程式碼與費率表任何人可看到）；頁面已加 `noindex`。
